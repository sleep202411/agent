# Multi-Panel Sequence Director

Preserve the user's subject, project facts, approved references, identity, exact copy, delivery constraints, and safety policy. Apply only the creative direction needed for the requested artifact.

## Apply the Skill

1. Identify the requested artifact and the supported capability.
2. Preserve immutable project and user constraints before adding creative direction.
3. Translate the direction into observable composition, camera, light, material, performance, motion, or editorial decisions.
4. Remove conflicting or decorative instructions that weaken the requested result.
5. Return the requested prompt, plan, analysis, image direction, or video direction without claiming unreported generation success.

## Prompt Authoring

<!-- fizzdragon:policy:prompt:start -->

Break the dramatic beat into complementary coverage rather than duplicate views. Assign each panel or shot a purpose, maintain character and prop continuity, vary shot scale deliberately, preserve eyelines and screen direction, and make the sequence readable in editorial order.

<!-- fizzdragon:policy:prompt:end -->

## Image Generation

<!-- fizzdragon:policy:image:start -->

Create a clean cinematic contact sheet of six distinct storyboard panels in a consistent 3-by-2 grid. Each panel must show a different purposeful shot in one continuous scene, with stable character identity, wardrobe, props, lighting and geography; progress from setup through action to payoff, with no decorative layout clutter or repeated framing.

<!-- fizzdragon:policy:image:end -->

## Video Generation

<!-- fizzdragon:policy:video:start -->

Stage one continuous dramatic beat using complementary coverage: establish geography, move to a readable medium action, isolate one decisive detail, reveal the reaction, and land on a clear payoff. Maintain identity, eyelines, screen direction, props and light across every change of framing.

<!-- fizzdragon:policy:video:end -->

## Boundaries

- Do not override explicit user requirements, approved references, permissions, safety policy, model capability, or tool contracts.
- Do not invent assets, approvals, project facts, dialogue, inspected evidence, or completed generation results.
- Do not add executable tools, third-party credentials, or direct provider calls.
- Use transferable creative decisions; do not reproduce protected characters, logos, or recognizable source scenes that the user did not provide.
