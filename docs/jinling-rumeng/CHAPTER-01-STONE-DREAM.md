# 《入梦金陵》第一章互动剧情脚本 V2.0

> 依据:[叙事设计总纲 V0.1](./NARRATIVE-DESIGN-BIBLE.md)
> 本文 §九 记录当前落地状态与差距 —— **§一~§八 是目标,§九 是现状,不一致时以前者为准。**

## 第一章：石上之梦

**原著来源：** 第一回开篇"补天遗石、一僧一道、顽石欲入红尘"相关情节
**玩家单次游玩时长：** 约 5—6 分钟
**全分支视频素材总量：** 约 12—15 分钟
**章节结构：** 编织式分支
**核心场景：** 西偏院画斋、青埂峰、人间幻境
**玩家身份：** 贾府画师
**固定主线结果：** 顽石决定进入红尘，并随一僧一道离开青埂峰
**核心互动数量：** 单次路径约 10—12 次
**主要视觉：** 真人电影级写实
**辅助视觉：** 宣纸、水墨、画卷转场

---

## 一、章节核心命题

本章不急于完整解释补天神话，也不告诉玩家这块石头未来会成为何物。本章只讨论一个问题：

> 当一块从未经历过人生的石头，第一次同时看见人间的温情、功名与离别，它是否仍愿意亲自进入其中？

玩家不能替石头决定是否入世。但玩家看见什么、如何行动、关注什么，会影响石头对人间的第一印象。

---

## 二、编织式分支结构

玩家第一次选择的是进入红尘的入口：**灯火**(温情、欢聚、家庭)、**高门**(功名、身份、权力)、**归途**(离别、死亡、新生)。

进入第一条路线后，玩家会遇到第二次选择：留在当前主题深入体验，或跟随一个人物／事件交叉进入相邻主题。形成六种单次游玩路线：

```text
灯火 → 灯火      高门 → 高门      归途 → 归途
灯火 → 高门      高门 → 归途      归途 → 灯火
```

三个主题形成循环：

```text
灯火 → 人们为了家庭追逐功名 → 高门 → 高门之外有人求告无门
     → 归途 → 旧人离开,新生命到来 → 灯火重新亮起
```

玩家单次不会看完三个完整主题，但可以经历两个相互关联的主题。

---

## 三、章节流程总览

```text
画斋夜深 → 玩家探索异常物品 → 亲自落笔进入画卷 → 青埂峰探索
→ 发现顽石与一僧一道 → 选择第一个红尘入口 → 第一主题体验
→ 选择深入或交叉 → 第二主题体验 → 回到青埂峰
→ 根据完整经历生成顽石感悟 → 顽石决定入世
→ 玩家选择观察神话线索 → 回画斋完成不同构图 → 引出姑苏、葫芦庙
```

## Scene 1：画斋夜深 — 00:00—00:30

荣国府，西偏院画斋。序章刚刚结束。房门已经关闭，管事的脚步声渐渐消失。玩家站在桌前。

桌上摆着：空白画卷、毛笔和砚台、"丹青"府牌、玩家画箱、一小块沾着泥土的石屑、一盏微微摇曳的烛灯。

房间没有背景音乐，只有风吹窗纸、木材轻响和远处打更声。

### 互动节点 1：自由查看画斋

| 对象     | 反馈                                             |
| -------- | ------------------------------------------------ |
| 府牌     | 背面新刻的「西偏院」；窗外同时传来一道院门落锁声 |
| 空白画卷 | 纸面短暂浮现一座山峰，眨眼后消失                 |
| 画箱     | 画材都在原位，角落多出一块从未见过的石屑         |
| 石屑     | 一声极远的铜铃；内部闪过不足一秒的五色反光       |
| 窗外     | 墙外似乎有两个模糊身影经过，再看时院中空无一人   |

**推进条件：** 查看任意两处后，砚台里的墨水自行泛起波纹，烛火忽然压低。

---

## Scene 2：落下第一笔 — 00:30—00:50

### 互动节点 2：调墨

玩家亲自拿起毛笔、在清水中润笔、蘸取墨汁、调整墨色浓淡。停留时间不同形成**淡墨／中墨／浓墨**，影响章节结束后的画作色调。

### 互动节点 3：落笔方式

点下一滴墨／横向拖出山脊／纵向拉出水痕／斜向画出一道裂纹。不同笔势形成不同的转场。

最终墨迹都逐渐勾勒成一座山、一片云、一块孤石。宣纸纹理慢慢变成真实山林。

---

## Scene 3：青埂峰下 — 00:50—01:20

雨后的青埂峰。云雾在山谷间流动。玩家以无实体的第一人称进入画中，可以在小范围内自由移动。

中央是一块不起眼的顽石：表面粗糙、长满苔藓、没有持续发光、没有面孔和表情、一侧有与序章相同的裂纹。

**未知旁白：** 天有缺，炼石以补。（玩家可主动抬头，天空极远处留有一道正在闭合的五色痕迹。）众石各得其用。……只有一块，被留了下来。

### 互动节点 4：寻找异常

靠近顽石(内部一声极轻的叹息)／触碰苔藓(像文字又像天然纹路的痕迹)／查看周围空缺(其他石块被取走后的凹痕)／走到山崖(山脚远处隐约可见城镇、车马和灯火)。

**推进条件：** 完成任意两次调查后，四季快速经过——春芽、夏雨、秋叶、冬雪、冰雪消融。顽石始终没有离开。

---

## Scene 4：山雾来客 — 01:20—01:43

山雾中同时传来三种声音：左侧木鱼、右侧铜铃、顽石内部的低语。

### 互动节点 5：先寻找什么

- **寻找木鱼** — 先看见僧人站在崖边，观察山下。
- **寻找铜铃** — 先看见道人；他尚未靠近，便已经看向顽石。
- **靠近顽石** — 听见它说：「他们终于又来了。」留下"僧道曾经来过"的隐藏线索。

一僧一道沿山路走来，形象朴素真实，不采用夸张仙侠装扮。

**僧人：** 山下今日倒热闹。
**道人：** 红尘中的热闹，从来不缺人看。
**僧人：** 只是不知，看热闹的人，可曾想过散场。

两人准备从顽石旁经过。

---

## Scene 5：叫住他们 — 01:43—02:00

### 互动节点 6：如何让僧道停下

| 方式     | 反馈                                       | 记录                 |
| -------- | ------------------------------------------ | -------------------- |
| 触碰顽石 | 石头立即开口：「二位且慢！」               | 顽石初始性格：急切   |
| 凝视道人 | 道人主动停下：「原来你还在这里。」         | 顽石初始状态：被发现 |
| 保持不动 | 僧道几乎走远，石头犹豫后才喊：「请留步！」 | 顽石初始性格：迟疑   |

**顽石：** 你们说的人间，究竟是什么模样？
**僧人：** 既然想看，便自己看一眼。
**道人：** 但你第一眼看见的，未必就是全部。

山雾向三面分开。

---

## Scene 6：红尘入口 — 02:00—02:12

三件真实物体从雾中出现：

- **左侧 灯笼** — 笑声、丝竹和孩子奔跑声
- **正前方 榜文** — 锣声、唱名声与高门开启声
- **右侧 白色花瓣** — 风铃、脚步和极轻的哭声

### 互动节点 7：第一次主题选择

玩家主动触碰灯笼／榜文／花瓣，决定第一段体验。

---

## 第一主题 A：灯火 — 02:12—02:48

玩家进入无名城镇的夜间灯会：孩子提灯奔跑、母亲替女儿整理发饰、年轻夫妻在街边买花、一户人家正在举行婚礼、一家老小围坐吃饭。

一个孩子从玩家身边跑过，小灯笼掉在地上。

### 互动节点 8A：遗失的灯笼

| 行动           | 反馈                             | 记录           |
| -------------- | -------------------------------- | -------------- |
| 拾起并追上孩子 | 「谢谢先生。」                   | 第一印象：善意 |
| 放在显眼位置   | 孩子与母亲返回寻找，母亲抱住孩子 | 第一印象：守候 |
| 不去触碰       | 灯笼被风吹向街角，最终熄灭       | 第一印象：错过 |

### 第二次主题选择

孩子的父亲从人群中赶来：「快些，今日放榜。若你哥哥中了，咱们家便不同了。」

→ 留在灯会，走向婚礼与家宴(**灯火 → 灯火**)／跟随父子前往放榜处(**灯火 → 高门**)

---

## 第一主题 B：高门 — 02:12—02:48

玩家进入放榜现场。人群围在新榜前。一名青年发现自己高中，父亲喜极而泣。蒙太奇：青年换上官服、宅院重新粉刷、新匾额升起、官轿从人群中穿过。玩家跟随人群来到一座高门前。

### 互动节点 8B：榜下之人

| 行动             | 反馈                           | 记录           |
| ---------------- | ------------------------------ | -------------- |
| 查看高中者       | 被众人簇拥进入高门             | 第一印象：荣耀 |
| 查看榜上其他姓名 | 雨水逐渐打湿那些无人关注的名字 | 第一印象：落第 |
| 查看门外百姓     | 有人手持诉状等待求见           | 第一印象：门外 |

### 第二次主题选择

门外一名求告者：「我的父亲死得不明不白。求大人替我们作主。」

→ 跟随新官进入高门(**高门 → 高门**)／留在门外跟随求告者(**高门 → 归途**)

---

## 第一主题 C：归途 — 02:12—02:48

玩家进入雨后乡间道路。一支送葬队伍缓慢经过。画面不展示逝者，只表现白幡、低头的人群、被亲人牵着的孩子、不断回头的老人、被雨水打湿的道路。

一片纸钱和一片白花同时落在玩家面前。

### 互动节点 8C：拾起什么

| 行动       | 反馈                               | 记录           |
| ---------- | ---------------------------------- | -------------- |
| 拾起纸钱   | 「走远些吧，莫再回头。」           | 第一印象：死亡 |
| 拾起花瓣   | 路旁屋门打开，一个女人抱着婴儿出现 | 第一印象：新生 |
| 什么都不拾 | 纸钱和花瓣一起被风吹远             | 第一印象：旁观 |

### 第二次主题选择

另一侧村中亮起数盏小灯：「今日孩子满月，进来喝碗酒吧。」

→ 继续跟随送葬队伍(**归途 → 归途**)／转向亮灯的人家(**归途 → 灯火**)

---

## Scene 7：第二主题体验 — 02:48—03:32

### 路径 1：灯火 → 灯火

玩家留在灯会。红绸从镜头前掠过，一场婚宴正在进行。玩家可以把掉落的花放回桌上、为老人让开座位、看向独自坐在角落的人。片刻之后宴席结束，宾客离开，灯笼逐渐熄灭。

**顽石：** 原来相聚的时候，人们都以为不会散。

### 路径 2：灯火 → 高门

玩家跟随父子来到榜下。哥哥果然高中。一家人先是拥抱欢呼，随后被前来道贺的人群分开。官差请高中者登轿，父亲和弟弟留在原地。

**顽石：** 原来一扇门打开，也可能让一家人走向不同的地方。

### 路径 3：高门 → 高门

玩家跟随新官进入府门：仆人列队、官服被整理、印章被郑重放在案上、众人开始改口称"大人"。玩家可以观察官印／镜中官服／门外越来越模糊的百姓。高门彻底关闭。

**顽石：** 人有了名字，又怕失去名字。

### 路径 4：高门 → 归途

玩家跟随求告者离开，来到一处简陋灵棚。死者家属仍在等待官府回应。一个孩子问：「门里面的人，真的会听见吗？」远处传来府中宴饮的声音。

**顽石：** 门里有人庆贺，门外有人等待。原来同一扇门，可以隔开两种人间。

### 路径 5：归途 → 归途

玩家继续跟随送葬队伍，最终停在山坡。众人离去后只剩一名老人。玩家可以陪他停留片刻／看向新土／转身看远处仍在耕作的人。老人最后轻声说：「日子还是要过。」

**顽石：** 人走了，路却没有停下。

### 路径 6：归途 → 灯火

玩家走向满月宴。屋内没有盛大庆典，只有一家人围着婴儿。老妇人点亮一盏小灯，放在孩子床边。门外送葬队伍的白幡仍能从远处看见。

**老妇人：** 愿他平平安安，长长久久。
**顽石：** 有人刚刚离去，也有人第一次看见灯火。

---

## Scene 8：回到青埂峰 — 03:32—04:02

第二主题中的最后一个视觉元素逐渐化为山雾。玩家回到青埂峰，一僧一道仍在原地。

**道人：** 看过这些，仍想去吗？

### 互动节点 9：玩家表达态度

靠近顽石／看向山下／后退／保持不动。玩家没有固定台词，但动作会被石头理解。

### 六种路径对应的顽石感悟

| 路线        | 感悟                                                   |
| ----------- | ------------------------------------------------------ |
| 灯火 → 灯火 | 相聚会散，可若从未相聚，又何来不舍？                   |
| 灯火 → 高门 | 人们为了家人追逐功名。可功名到了，家人却未必仍在身旁。 |
| 高门 → 高门 | 既然名字如此重要，我也想知道，自己会得到怎样的名字。   |
| 高门 → 归途 | 得到名字的人走进高门。失去名字的人，却连门也敲不开。   |
| 归途 → 归途 | 人终会离去，可留下的人仍要继续向前。                   |
| 归途 → 灯火 | 有人离去，有人到来。原来人间从不会真正停下。           |

### 公共台词

**顽石：** 我看见的仍只是片刻。好也罢，苦也罢，我愿亲自走一遭。
**道人：** 入了红尘，便不能只挑自己喜欢的看。
**僧人：** 今日一心想去。来日梦醒，未必还愿记得。
**顽石：** 若从未去过，又怎会知道？

---

## Scene 9：顽石化形 — 04:02—04:30

僧人伸手触碰顽石。石头表面的裂纹出现微弱五色光线。变化真实、克制：苔藓脱落、粗糙表面逐渐收缩、石体变得温润、最终成为可以随身佩戴的大小。

石上出现文字，但被僧人的手遮住一部分。

### 互动节点 10：选择观察对象

| 观察     | 所见／所闻                                                     |
| -------- | -------------------------------------------------------------- |
| 触碰石头 | 三个极短未来残影：婴儿胸前的玉光／花瓣与小锄／大雪中的红色背影 |
| 辨认文字 | 短暂看到「莫失莫忘」，后面的内容没有看清                       |
| 观察僧人 | 「总要亲自疼过，才肯相信。」                                   |
| 观察道人 | 「愿去容易，愿回却难。」                                       |
| 保持距离 | 只听见石头内部第一次出现类似心跳的声音                         |

**僧人：** 走吧。

一僧一道带着石头进入云雾。原本放置石头的位置只剩一个浅浅的空痕。

---

## Scene 10：画斋归来 — 04:30—04:45

山雾转化成宣纸淡墨。玩家重新站在画斋桌前，毛笔仍然停在纸上。现实中似乎只过去了一瞬间。

画卷上已经出现：青埂峰、僧道背影、顽石离去后的空位、玩家两次主题经历的象征物。例如：

- 灯火 → 高门：山下同时出现一盏灯和一扇朱门
- 高门 → 归途：朱门外有一条消失在雾中的白色道路
- 归途 → 灯火：远路尽头重新亮起一盏小灯

---

## Scene 11：完成第一幅画 — 04:45—05:12

### 互动节点 11：选择画面主体

玩家通过凝视确定画面中心：顽石／一僧一道／第一个红尘主题／第二个红尘主题／空下来的石座。

### 互动节点 12：完成最后一笔

笔的位置决定画作的最终情绪：点在山下(强调人间)／点在石旁(强调选择)／点在僧道背后(强调命运)／点在空石座(强调离开)。

作品名称由完整路径和构图共同生成：

| 路线        | 候选作品名                           |
| ----------- | ------------------------------------ |
| 灯火 → 灯火 | 《灯尽人散》《人间一夜》《青峰灯火》 |
| 灯火 → 高门 | 《灯下高门》《一门两途》《逐名》     |
| 高门 → 高门 | 《门内门外》《榜上有名》《朱门》     |
| 高门 → 归途 | 《门外无人》《求告》《高墙白幡》     |
| 归途 → 归途 | 《路未停》《送行》《空山归人》       |
| 归途 → 灯火 | 《一灯初生》《去来之间》《长夜新火》 |

画卷右下角出现一枚小印：**第一笔**

---

## Scene 12：姑苏旧画 — 05:12—05:30

门外响起两声轻敲。

**仆役：** 画师，库房里清出一卷旧画。管事说，或许您用得着。

一卷旧画从门下轻轻推进来。玩家走近，标签上写着：

> 姑苏
> 葫芦庙

### 互动节点 13：触碰旧画

玩家手指碰到标签，短暂听见：一个男人朗读诗文、女孩的笑声、寺庙钟声、火焰爆裂声。声音互相重叠，又突然消失。

画面切黑。出现下一章标题：

> 第二章
> 一眼风尘

第一章结束。

```text
first_action       = kindness | waiting | missed
                   | glory | failure | outsider
                   | death | birth | observer
second_theme       = lantern | gate | journey
woven_route        = lantern_lantern | lantern_gate
                   | gate_gate | gate_journey
                   | journey_journey | journey_lantern
player_attitude    = supportive | curious | cautious | neutral
myth_clue          = future_visions | jade_text | monk_words | taoist_words | untouched

```

## 五、变量的后续影响

第一章的选择不会改变原著事件，但会影响玩家未来"先看见什么"。

- **灯火倾向较高** — 更容易注意家庭情感、主仆之间的善意、娇杏回眸时的情绪、甄士隐与英莲的父女关系。
- **高门倾向较高** — 更容易注意贾雨村的功名欲望、身份等级、门第规矩、官府和家族权力。
- **归途倾向较高** — 更容易注意英莲失踪前的征兆、甄家由盛转衰、死亡和离别意象、僧道留下的神话线索。
- **混合路线** — 「灯火 → 高门」下一章更容易注意到：贾雨村追逐功名并不只是个人野心，也与他渴望改变自身处境有关。「高门 → 归途」则更容易注意到：权力如何决定谁能被听见、谁会被遗忘。

## 七、制作验收标准

1. 玩家一次只能完整体验两个主题，不能看完三个主题。
2. 第二次选择必须由人物或事件自然引导，不能弹出现代菜单。
3. 六种路线必须拥有明显不同的内容和感悟。
4. 汇流后不能清空选择结果。
5. 石头的台词必须根据玩家完整路线变化。
6. 玩家画作必须同时体现两次主题经历。
7. 至少两个第一章变量要在第二章产生可见反馈。
8. 交互不能只是"点击后播放原本的视频"。
9. 任何互动停顿不能长到破坏电影节奏。
10. 石头、一僧一道和神话内容保持克制，不使用廉价仙侠效果。
11. 真人电影层和水墨转场层必须清晰区分。
12. 章节最终仍然忠于"顽石主动要求进入红尘"的固定主线。

```text
安静    画斋夜深
  ↓
异常    石屑、铜铃、墨迹
  ↓
```

这也正是顽石仍然决定入世的原因——它想经历的从来不是某一种人生，而是这一切彼此纠缠的完整人间。

### 9.2 为什么六条路线不汇流

平台是**纯分支树,没有状态引擎**(`story-experience-manifest-compiler.ts` 硬编码 `stateDefinitions: []`)。

一旦六条路线汇流,系统就再也分不清玩家走的是哪条 —— 而验收 #4「汇流后不能清空选择结果」、#5「石头台词随完整路线变化」、#6「画作同时体现两次经历」全都依赖它。

⇒ **"走到哪个结局"是本章唯一能持久保存的状态。** 尾巴按路线复制是这个约束的直接代价。

**节点复制 ≠ 素材复制**:六个「Scene9 顽石化形」节点内容完全相同,将来挂**同一条视频**。它们是全图唯一的纯结构冗余。

---

### 9.3 脚本有、图里没有的(按严重程度)

#### 1. 八个状态变量,一个都存不下

`first_brush`、`stone_temperament`、`first_action`、`player_attitude`、`myth_clue`、`painting_focus` 在图里**没有对应叶子**。

| 变量                           | 图里的处理                                           |
| ------------------------------ | ---------------------------------------------------- |
| `woven_route`                  | ✅ 由结局编码,是唯一活着的                           |
| `first_action`(9 种)           | 有独立节点和各自的反馈镜头,但**汇流后区分不出**      |
| `first_brush`(墨色 3 × 笔势 4) | 收在 Scene2 单节点内                                 |
| `player_attitude`(4 种)        | 收在 Scene8 单节点内                                 |
| `myth_clue`(5 种)              | 收在 Scene9 单节点内                                 |
| `painting_focus`(5 种)         | **已移除** —— 原本做成了 6 份重复的选择卡,去重时折叠 |

全组合是 3×3×3×3×2×4×5×5 ≈ **十万级路径**,不可能用分支树表达。

#### 2. 验收 #7 现在不可能

「至少两个第一章变量要在第二章产生可见反馈」—— 跨章读取变量**必须有状态引擎**。`woven_route` 能靠结局传递,但下一章读不到它。

#### 3. 验收 #2／#8:所有交互都是按钮

脚本要的是**自由转头、凝视、靠近、拾取、触碰、跟随、物品操作、构图凝视**;平台只有 `core.choice`(带标签的选项列表)和 `core.checkpoint`(通用「继续」按钮)。

图里 7 个选择点**全部会渲染成现代按钮菜单**,直接违反:

- 验收 #2「第二次选择必须由人物或事件自然引导,不能弹出现代菜单」
  —— 已尽力缓解:选项标签写成剧中动作(「跟随父子前往放榜处」「留在门外跟随求告者」),而不是抽象主题名。但**渲染形态仍是按钮**。
- 验收 #8「交互不能只是点击后播放原本的视频」

#### 4. 自由探索没有载体

互动节点 1(查看任意两件后推进)和节点 4(完成任意两次调查后推进)是**探索-计数-放行**,不是分支。平台没有这种渲染器。图里它们是普通 auto 节点,探索内容目前只存在于脚本里。

### 9.4 平台欠账清单

按解锁价值排序:

1. **状态引擎** —— 解锁 8 个变量、跨章反馈(#7)、以及《荣宁府图》的区域权限/盛衰褪色。**这一项不做,后面每一章都会重复今天的削减。**
2. **非按钮交互渲染器** —— 凝视/靠近/拾取/触碰。解锁 #2、#8,以及序章「点画斋」那个至今无载体的隐藏热区。
3. **自由探索渲染器** —— 计数式放行。
4. **checkpoint 可授权文案** —— 现在写死通用「继续」,`StoryCheckpointExitSchema` 只有 `kind` + `nextNodeId`,加一个可选本地化字段即可。
