## SC03-PROD-CARD-V01：游廊风灯

状态：DRAFT
覆盖任务：`S01-SC03-B01-VIDEO-MAIN`、`S01-SC03-B02-VIDEO-WAIT`、`S01-SC03-C03-VIDEO-OUTCOME-*`
场景职责：用一个可信的空间危机第一次验证玩家“先顾人、先顾物还是暂时失措”；动作必须自然发生在入府路上，不做孤立小游戏，也不能借解袖制造越界肢体接触。

### 1. 主动作链

| 阶段        | 建议时长 | 动作                                                     | 连续性要求                             |
| ----------- | -------- | -------------------------------------------------------- | -------------------------------------- |
| A 入廊      | 8–12 秒  | 仆妇在前侧提风灯，黛玉居中，玩家 POV 在她右后约 1.1 米   | 轴线、脚步、灯位和荐书袖口位置建立清楚 |
| B 风起      | 4–7 秒   | 横风穿廊，风灯沿提梁向内侧摆斜，侧门铜扣靠近黛玉外侧宽袖 | 火焰仍在防风罩内，不突然爆燃           |
| C 勾袖/滑信 | 2–4 秒   | 铜扣勾住衣袖外缘；黛玉停步；玩家袖内荐书同时滑出约 3–5cm | 三个风险同时可见，但不要求玩家同时处理 |
| D WAIT      | 3–5 秒   | 仆妇稳住提梁、黛玉不硬扯、荐书继续将滑未滑，等待玩家动作 | 自然循环，不在灯摆极值或眨眼时拼接     |
| E 四结果    | 8–13 秒  | 扶灯、压袖让黛玉抽回、护信或无动作分别产生人物反应       | 共用同一 WAIT 结束帧和空间状态         |

### 2. 风灯结构与物理

- 风灯为晚期帝制江南宅院使用的六角手提防风灯：深色硬木/旧铜细框、半透明角片或云母防风片、顶部通风帽、上方提环和短木提梁、内部深置小油杯。
- 灯体高度约 32–38cm，最大宽度约 20–24cm；仆妇单手提梁时灯底距地约 65–80cm，不在人物脸侧晃动。
- 一面设窄小维护门，使用贴近框体的旧铜旋扣。旋扣只突出约 8–12mm，足以勾住宽袖边缘，但不能像尖锐鱼钩。
- 横风使灯体绕提环摆动约 12°–18°；火焰在防风罩内偏斜，罩片保持完整，不发生玻璃碎裂或纸罩燃烧。
- 黛玉衣袖只被侧门铜扣勾住外层布边，不被火焰、热罩或灯体夹住；她若硬拉会使灯摆幅增加，所以先停住。
- 玩家扶灯时接触冷却的上框/提梁节点；不抓罩片、不把手伸近通风帽、不碰仆妇持握手。
- 风灯后续需要独立 GLTF：提环、提梁、灯体摆轴、维护门/旋扣、油杯和火焰代理均为稳定节点。

### 3. 空间与轴线

- 游廊为单侧开敞、单侧白墙/深木窗的抄手游廊；横风从开敞侧进入，风向在所有片段固定。
- 仆妇在画面前左提灯，黛玉在中景偏右，玩家在黛玉右后；三者不排成直线，确保手、灯、衣袖和荐书都有可读空间。
- 180°轴线沿游廊纵向建立，所有结果片保持前进方向一致；不得为了拍手部突然切到第三人称或镜像灯位。
- 风灯摆向画面中央，维护门铜扣朝黛玉外袖；正式灯模型必须固定门向，不能在不同片段换到另一面。
- 玩家荐书位于自己内侧袖袋，滑出位置在画面下缘偏右；不与黛玉袖口或风灯占同一像素区域。

### 4. 玩家 POV 四结果

| 路线       | 玩家动作                                             | 灯/袖/信结果                             | 人物即时反应                 |
| ---------- | ---------------------------------------------------- | ---------------------------------------- | ---------------------------- |
| A 先扶灯   | 右手从下方进入，托住冷上框并把摆角压回 5°以内        | 仆妇复稳提梁；黛玉自己松袖；荐书仍露一角 | 仆妇认可手稳；黛玉感谢观察力 |
| B 先解袖   | 双手只压住铜扣旁的衣料外缘，给出松弛量让黛玉自行抽回 | 灯仍由仆妇控制；荐书继续露出             | 黛玉先退后确认玩家没有抓腕   |
| C 先护荐书 | 右手压回自己的荐书，左手不越过黛玉身体               | 仆妇扶灯，黛玉自己解袖                   | 黛玉注意玩家对信的紧张       |
| D 无动作   | POV 只有自然惊退/呼吸，不生成夸张抓空                | 仆妇扶灯，黛玉自己解袖，危机不阻断主线   | 仆妇提醒；黛玉留步等玩家     |

- A/B/C/D 都是有效叙事选择，不显示“正确/错误”；A/B 建关系，C 建身份悬疑，D 产生轻微尴尬但不惩罚操作能力。
- B 路线严禁抓住黛玉手腕、手掌、前臂或把袖子从她身上用力拉下；玩家只制造布料松弛量。
- A 路线手掌不能遮住火焰和灯罩，动作接触点由风灯 GLTF 的 `grip_stabilize` 锚点定义。

### 5. 第一视角摄影与合成

- 眼高 1.62m，等效 45–50mm；风起前不推镜，危机通过物体进入动作区完成，不用镜头震动制造紧张。
- 玩家手采用 [15-PLAYER-POV-PRODUCTION-SPEC.md](./15-PLAYER-POV-PRODUCTION-SPEC.md) 的运行时合成，视频底片不烧入固定肤色手。
- 干净底片必须交付黛玉衣袖、灯体/铜扣、仆妇手和荐书的遮挡层与深度代理。
- WAIT 构图在 16:9 中把灯、黛玉外袖和荐书三点保持在中央 68%；9:16 需要独立重构，不直接裁掉荐书。
- 选择 UI 不盖住灯钩、衣袖或荐书；动作可通过指向对象、键盘/手柄四向和辅助列表等价触发。

### 6. 光线、声音与材质

- 场景为阴天日间廊光，风灯火焰只提供局部微暖色和物理信息，不作为人物主光。
- 风起由竹叶、窗纸、衣料和火焰偏斜共同表现，不使用奇幻粒子或夸张尘暴。
- 声音顺序：远风—木廊轻响—灯框/提环细响—衣料被勾—荐书纸摩擦；不能用游戏警报音。
- 扶灯成功后先听见提环摆幅收小，再听对白；解袖时只用布料/铜扣轻擦，不做撕裂声。
- 风灯木、旧铜、角片/云母、油杯和火焰必须分材质；生成参考不等于历史工艺结论。

## SC04-PROD-CARD-V01：贾母相见

状态：DRAFT
覆盖任务：`S01-SC04-B01-VIDEO-MAIN`、`S01-SC04-B02-VIDEO-GUEST`
原著主位：黛玉与贾母的相认、拥抱与对贾敏的追忆。玩家不抢特写、不插入选择、不获得情绪安慰。

### 1. 叙事与镜头职责

| 节拍     | 目标时长 | 镜头职责                                                                             | 禁止事项                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| B01 相认 | 45–60 秒 | 让玩家在场见证黛玉终于被外祖母接住；完整保留伸手、靠近、拥抱、落泪和“往后这里就是家” | 不切玩家反应，不弹 UI，不让荐书异象抢走拥抱              |
| B02 看客 | 25–35 秒 | 情绪平复后，贾母才把注意力转向玩家；完成近前、看信、停指、暂留和把信交熙凤           | 不把贾母写成审讯者，不提前揭破太虚，不让熙凤盖过贾母决定 |

### 2. 空间与轴线

- 正厅中轴由贾母座位、脚踏、前方留白和后屏构成；贾母不是宫廷高台，而是家宅中所有人自然围绕的中心。
- 黛玉从画面前左进入中轴，玩家 POV 在她右后方约 1.2 米，保持“同行但不是母女相认主角”的位置。
- 熙凤位于贾母右侧后方约 1.5 米，B01 不前抢；B02 才从右侧进入荐书递接线。
- 其他人物分布在两侧景深，不形成整齐朝班；她们的泪与避让只作为空间反应。
- 180°轴线沿“玩家—黛玉—贾母”建立。B01 期间不得跨轴；若使用补充特写，必须从同侧取得。

### 3. 第一视角摄影

- 基准眼高：成片虚拟眼高 1.62 米；POV 不因玩家自定义性别或出身改变。
- B01 起始机位：距贾母约 4.2 米、距黛玉约 1.2 米，等效 40–45mm 镜头，水平视角接近真人注视。
- 黛玉向前时，POV 只跟进 0.4–0.6 米后停下；相拥期间不绕行、不推大特写、不模拟偷窥式探头。
- 拥抱构图：黛玉与贾母占中央安全区约 42%–55% 画宽，手与肩完整可见；玩家距离让两人的情绪成立，也保留“客”的边界。
- B02 转向：贾母先结束与黛玉的眼线，再看向镜头。玩家在台词“近些，让我看看”后向前 0.7 米；运动时长 1.2–1.6 秒，带自然呼吸而非游戏漂移。
- 贾母看玩家时，目光落在镜头光轴；看荐书时只下降约 12°–18°，避免演员眼神完全离开玩家。

### 4. 表演节拍

#### B01 相认

1. 贾母先看清黛玉，吸气停住，手抬到一半才真正伸出。
2. 黛玉保持礼数的一瞬被“我的儿”打断，先收袖再向前，不扑抱。
3. 贾母揽住黛玉时，一手在肩背、一手握前臂；动作带年长者真实力量，不颤抖卖弱。
4. “怎么这样瘦”不是评判外貌，而是失女之后迟到的疼惜。
5. 黛玉只说“外祖母”，其余情绪由呼吸、肩膀和回握完成。
6. “往后这里就是家”之后留 2–3 秒静默，让室内人的眼泪和衣料声进入。

#### B02 看客

1. 贾母先把黛玉的手安稳放回膝上，确认她没有被突然松开，再转向玩家。
2. “近些，让我看看”温暖但具有决定空间距离的权威。
3. 贾母看旧署名时有真实旧识反应；看到淡红封印时只停指 0.6–0.9 秒，不做惊恐表情。
4. “旧人我认得，旧情也认得”说给玩家，也是在压住旁人的追问。

### 6. 表演节拍

#### B01 正式装进厅

1. 宝玉脚步快但不是奔跑，进门后先收步看贾母，再在余光里发现黛玉。
2. 黛玉的“一大惊”表现为呼吸停半拍、目光确认、手指轻收，不使用瞪眼或后退。
3. 宝玉也被新面孔吸引，但礼数先于好奇；他请安时不能继续盯黛玉。
4. 贾母命他离开后，他转身经过黛玉视线边缘，停顿不超过 0.5 秒，不说台词。

#### B02 家常装返回与厮见

1. 返回步态与 B01 同源，但换下正式装后肩颈更松，显出在家中的自在。
2. 贾母说“外客未见，就脱了衣裳”时，宝玉不是受训挨骂，而是立刻意识到应先厮见。
3. 作揖后，宝玉先看清黛玉，再由眼神生出笑；“曾见过”像真切发现，不像预设情话。
4. 黛玉不主动迎合，只在惊疑与熟悉之间保持克制；她的沉默必须有可读的回望。
5. 宝玉转向玩家前，先把与黛玉的停顿完整留足；玩家获得的是被他顺势注意，不是三角恋抢位。

### 7. B03 WAIT 与分支起点

循环长度：4–7 秒。宝玉问完“你从哪一册里来的”后：

1. 目光停在镜头 1.0–1.5 秒，眉梢仍有好奇笑意。
2. 视线下降到荐书或玩家当前信物 0.4–0.7 秒，不伸手抢取。
3. 呼吸带动项圈与丝绦极轻运动；通灵玉保持在可抓取层，其他佩饰不互相穿模。
4. 目光回到镜头，自然眨眼后回到可循环姿态。

四条反应片全部从同一 WAIT 结束姿态起步；只改变台词、眼神、与信物距离和黛玉的即时回应，不改变服装、座次或玉的位置。

- 实拍/数字人动作使用隐藏磁吸或快速脱离结构；演员动作路径不得与长辫、领扣、寄名锁和护身符缠绕。
- 摘下后，胸前必须仍清楚看见项圈、寄名锁与护身符；玉的原位置留下自然空位和轻微衣料回弹。

- QTE 出现前用玉、手臂和视线形成天然运动提示；不显示发光圆圈、倒计时条或“接住玉”大字。
- 鼠标/触摸可直接朝轨迹拖/点；键盘和手柄提供“接、护、呼唤、不动”四个等价方向，不要求精密瞄准。
- 辅助模式把判定窗延长至 1.4–1.8 秒，并允许暂停式选择，但剧情内宝玉仍完成松手，不回滚动作。

### 6. 表演约束

1. 宝玉听见“没有”后的第一反应是受伤与不可理解，不是对黛玉愤怒。
2. 情绪变化次序为：笑意停住—目光确认—呼吸变快—手去摘玉—声音失控；禁止一帧切成狂怒脸。
3. “它是什么好东西”是对玉和等级象征的否定，不是对房内任何人的威胁。
4. 摔出后宝玉胸口起伏、眼眶可湿，但不能立即悔悟、向玩家道歉或恢复平静。
5. 即使瞋视，眼神底层仍有情；不得表演成暴力反派、醉酒或精神恐怖片角色。

### 7. 声音与材质

- 黛玉回答后先降低音乐 1–1.5dB，让呼吸、丝绦摩擦和衣料回弹成为动作预告；不使用低频冲击“黑化”。
- 摘玉声音由丝绦滑动、轻金属/玉碰撞和衣料摩擦组成，不使用断绳爆裂声。
- 玉飞行没有魔法呼啸；丝绦擦手可有极短纤维声。
- 落地声需要分别录制玉落软垫、玉擦木面、玉入掌、玉与丝绦共同落地四组素材；不得使用玻璃破碎声。
- 众人反应从第一声落点之后进入，避免所有角色在玉离手前整齐尖叫。

### 10. 拒收与晋级

拒收：摘玉变成勒颈、断绳或四件物一起脱落；玉朝黛玉/玩家脸投掷；宝玉换脸、变成纯暴力反派；玉尺寸、色泽或丝绦改变；QTE 发光游戏化；不同结果重置人物位置；玩家可以阻止摘玉而取消原著动作。

生产卡进入 REVIEWED 需要：

- 四阶段动作板通过脸、手、玉、丝绦和胸前三件留存物连续性审看；
- 空间卡锁定投掷空地、软垫/木面边界和四条路线的安全运动范围；
- 玉的 GLTF、丝绦模拟、碰撞代理和四种声音完成最小可复现测试；
- 主片释放帧能与四条结果无缝拼接，且 16:9/9:16 都不丢失关键动作；
- 审看确认宝玉不是攻击黛玉，玩家只改变局部物理与关系后果；
- 无动作、辅助输入、键鼠、触屏和手柄路径全部可完成主线。
