# 世界规则与原创玩家系统

状态：REVIEWED · v0.2
最后更新：2026-07-10
关联决策：D-001、D-002、D-003、D-004

## 1. 设计目标

玩家必须感到“这是我创建的人进入了红楼”，而不是“我暂时借用了一个固定主角”。同时，原创玩家不能抢走原著人物的中心事件，也不能因为身份含糊而像透明摄像机一样旁观。

目标模型：

    玩家创建原创角色
      → 无字命册赋予世界内身份
      → 原著人物承认玩家存在
      → 玩家参与事件过程与余波
      → 原著锚点保留
      → 玩家发展独立关系和结局

## 2. 无字命册

太虚幻境中存在一本没有写入十二钗正册、又不属于任何副册的命册。它不记录固定命运，只记录玩家亲自做出的选择。

无字命册承担四个产品职责：

1. 为角色创建提供世界内解释。
2. 解释玩家为什么不是原著人物，却能影响原著事件。
3. 作为章节、存档、回放与结局收藏的统一视觉载体。
4. 为后续季节提供长期谜团：谁把这一页放进太虚幻境，为什么警幻仙姑没有预写玩家的命运。

命册不是常驻系统面板。它只在序章、重大选择回响、章节结束和隐藏线索中出现。

## 3. 玩家进入世界的方式

已确认设定：玩家在太虚幻境完成角色创建后，不以现代穿越者口吻进入剧情，而是作为红楼世界内部真实存在的原创人物醒来。玩家保留“自己的选择属于自己”的主观意识，但没有可用于破坏时代语境的现代身份与现代知识。

世界内共同身份：

> 玩家是贾母故交的晚辈，持一封与贾敏生前旧情相关的荐书来到荣国府。荐书足以让玩家被暂时接纳，却存在一处只有细看才会发现的异常。

荐书由无字命册把玩家写入红楼世界时一并生成。旧署名、旧纸和贾敏旧情在这个世界中都能找到真实对应；异常只存在于封口：灯下转动时会出现一枚现实印谱中不存在的淡红纹印，与无字命册落在玩家姓名旁的印记一致。

这个身份保证：

- 玩家可以合法进入贾母的会客场景；
- 玩家不是贾府奴仆，不受固定职业绑死；
- 玩家可以与黛玉产生“同为初来客”的连接；
- 王熙凤有理由审查玩家；
- 玩家能在后续季节继续留府或往返金陵；
- 身份可信度可以成为长期系统，而不只是第一季门票。

## 4. 角色创建内容

### 4.1 名字

- 玩家自由输入名字，建议 1–8 个字符。
- 名字出现在命册、荐书、存档、动态字幕和部分道具上。
- 正式配音不朗读自由输入名字；演员使用“你”“这位小友”“新来的”等自然称呼。
- 需要姓名的近景道具使用运行时文字图层或预渲染合成，不为每个名字生成视频。

### 4.2 出身

出身决定世界内来历、初始专长、信物和少量专属反应，不生成完全不同的主线。

#### ORIGIN-WEAVE：江宁织造故人之后

- 叙事优势：识别织法、纸张、印章与府中采买。
- 初始信物：半幅云锦样或旧织牌。
- 人物倾向：王熙凤更快注意玩家，黛玉对旧物产生兴趣。
- 专属能力：看出物件年代与制作异常。

#### ORIGIN-KIN：贾府故交晚辈

- 叙事优势：熟悉称呼、座次与旧交关系。
- 初始信物：故交私印或旧名帖。
- 人物倾向：贾母与王夫人较容易接受，熙凤会试探玩家是否借势。
- 专属能力：在礼法压力下获得更稳妥的应答。

#### ORIGIN-MEDIC：金陵医馆学徒

- 叙事优势：观察呼吸、疲惫、药香与情绪变化。
- 初始信物：药香囊或旧方笺。
- 人物倾向：更早察觉黛玉不适，宝玉对玩家携带的药物好奇。
- 专属能力：发现人物身体和情绪状态的非语言线索。

### 4.3 性格专长

玩家选择一个主要倾向。它不是结局积分，而是解锁不同的行动方法。

- TRAIT-HEART：重情。保护、安慰、替人承担。
- TRAIT-CAREFUL：谨慎。观察、保密、遵守边界。
- TRAIT-QUICK：机敏。试探、识破、临场转圜。

所有玩家都能完成主线。专长提供额外选项或更好的信息，不把其他玩家变成“错误答案”。

### 4.4 性别与外貌

第一季以第一视角为主，不让预录视频依赖完整玩家脸部。建议支持：

- 玩家自定义称谓或外在呈现；
- 个人资料页显示玩家选择或生成的肖像；
- 正式视频使用不露正脸的第一视角；
- 需要手部时使用服装袖口与构图弱化身体差异；
- 演员尽量使用中性称呼；必须区分称呼的镜头才制作有限语音变体。

不在第一季提供会导致每段视频排列组合爆炸的全身捏脸投影。

## 5. 玩家长期成长

### 5.1 关系状态

关系不是公开数值条，而是由可理解的“印象”组成。

- REL-DAIYU：黛玉信任。陌生 → 留意 → 同为客 → 私语相托。
- REL-BAOYU：宝玉态度。好奇 → 投契 / 戒备 → 主动相邀。
- REL-XIFENG：熙凤判断。审视 → 可用 / 可疑 → 拉拢 / 设防。
- REL-HOUSE：府中立足。暂留 → 有人担保 → 有自己的位置。

玩家可在章节回顾中看到文字化回响，例如“黛玉记得你在游廊没有追问”，但不直接展示 +2、-1。

### 5.2 身份可信度

IDENTITY-CREDIBILITY 记录荐书和玩家陈述是否自洽。它影响谁愿意担保玩家、是否出现身份危机，以及坏结局是否可触发。

### 5.3 命册洞察

LEDGER-INSIGHT 记录玩家发现无字命册、荐书异常和太虚印记的程度。它用于隐藏剧情，不与普通人物关系混成一项万能分数。

## 6. 原著边界

### 6.1 玩家可以改变

- 自己在场或缺席；
- 谁先注意自己；
- 是否得到人物信任；
- 某个动作由谁完成；
- 原著事件造成的局部物理结果；
- 原著未写出的私下谈话和余波；
- 自己是否留在故事中。

### 6.2 玩家暂时不能改变

- 第一季原著锚点是否发生；
- 黛玉与宝玉的核心人物关系；
- 原著人物为了讨好玩家突然违背性格；
- 通过一个按钮永久改写所有人物命运。

未来若设计架空大分支，必须把“偏离原著”作为明确世界事件，并承担后续内容成本，不能悄悄发生。

## 7. 第一季玩家目标

表层目标：让荣府承认荐书，决定自己能否留下。
关系目标：在同日进府的黛玉、审视自己的熙凤和好奇的宝玉之间建立第一组真实关系。
隐藏目标：发现荐书上的异常与无字命册有关，并决定把秘密交给谁。

## 8. 第一视角写作规则

1. 角色必须有理由看向镜头，而不是对空镜念台词。
2. 玩家站位、视线高度、递接物方向必须跨镜头连续。
3. 玩家选择代表可执行的语言或动作，不能是作者对剧情的评论。
4. 玩家没有说出口的内心判断可进入命册回响，但不能冒充角色听见的台词。
5. 演员对玩家选择的反应必须先于下一个主线事件。
6. 需要玩家姓名的内容使用动态 UI、字幕或道具合成，不要求演员朗读任意名字。

## 9. 已确认与待评审

- 已确认保留三种出身，共用故交晚辈与荐书入口。
- 已确认玩家不保留现代穿越者身份和现代知识。
- 已确认荐书异常为灯下可见、与无字命册相同的淡红纹印。
- 玩家年龄范围是否明确为少年阶段，以减少时代礼法对跨性别场景进入的限制。
- 荐书的署名人和贾敏旧情如何写得既可信又不过度增加新人物。
- 玩家是否在第一季结尾恢复太虚幻境记忆。
