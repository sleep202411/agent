## 规则

- review 资产不能直接进入 Seedance 正式任务。
- approved 资产必须在 Asset Manifest 中拥有稳定 ID。
- 角色、道具和场景资产必须记录最终生成提示词和参考图。
- 不把生成图中的文字、按钮或自由姓名直接烧进正式产品。
- 参考图中的印面、药材、织法和建筑不等于历史考据结论；进入 LOCKED 前必须完成相应专业复核。
