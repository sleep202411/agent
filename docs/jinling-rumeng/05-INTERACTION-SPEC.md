# 互动与玩家体验规范

状态：DRAFT · v0.1
最后更新：2026-07-10

## 1. 设计原则

- 互动必须发生在剧情内部，而不是把电影暂停成答题页。
- 台词选择和物理动作使用不同界面，不用同一种光点承载所有操作。
- 每次选择后先播放人物反应，再进入汇合或新分支。
- UI 平时退出画面；只有交互、暂停、缓冲或用户主动唤起时出现。
- 操作难度不决定是否能看到核心剧情；辅助模式不降低叙事结果。
- 表演、运镜和固定机位道具动作优先使用视频；交互由叠加层接管，不为固定镜头额外建立实时 3D 舞台。

## 2. 场景模式

### MODE-FILM：电影播放

- 默认全屏播放，字幕开启。
- 控件自动隐藏；鼠标移动、触屏或键盘操作后短暂出现。
- 支持暂停、继续、音量、字幕、清晰度、退出和已看跳过。
- 不常驻显示“第 2/9 场、22%”式进度条。

### MODE-DIALOGUE：真人应答

- 视频进入专门拍摄的等待姿态或自然短循环。
- 2–4 个选项置于画面安全区底部，不遮挡人物眼睛和手部。
- 选项写玩家真正会说的话或做的事，不写作者评价。
- 选择后立即锁定输入并播放独立反应片。

### MODE-ATTENTION：视线观察

- 用于 SC01、SC04 等“注意什么”的选择。
- 热点必须落在真实人物或物件上，并随构图校准。
- 视线停留或点击均可触发；提供键盘焦点列表。
- 不使用持续闪烁的白色光圈破坏电影画面。

### MODE-ACTION：物理动作

- 用于扶灯、护人、递信、接物等动作。
- 操作提示只描述动作，不提前泄露结果。
- 需要独立成功、替代动作和无操作后果片。

### MODE-QTE：高潮判断

- 第一季只用于摔玉高潮。
- 正常、延长、无时限三种模式使用相同剧情奖励。
- 选择窗口必须通过声音、字幕与视觉共同表达。
- 键盘、鼠标、触屏和手柄均可完成。

### MODE-PROP-3D：3D 道具检查

- Three.js / GLTF 只展示玩家必须自由旋转、缩放并从不同角度发现线索的荐书、通灵宝玉等关键道具；命册开合、毛笔与落印属于固定电影镜头，不进入此模式。
- 支持旋转、缩放、聚焦标记与恢复默认视角。
- 线索来自真实几何、纹理或光照角度，不用无意义转模型拖时间。
- 低性能或 WebGL 不可用时提供等价的高分辨率多角度检查，不丢剧情。

### MODE-PANORAMA：360°空间探索

- 用于 SC10 等有限、叙事密集的空间。
- 每个热点必须揭示状态、关系或结局条件。
- 提供热点列表、方向指示、键盘转向与减少眩晕选项。
- 不做与剧情无关的开放世界收集。

## 3. 玩家创建

流程：名字 → 出身 → 性格专长 → 信物确认 → 命册落印。

- 每步均可返回修改。
- 选项同时说明叙事风格，不展示“最佳属性”。
- 创建结果在进入 SC01 前提供一次完整确认。
- Mock 阶段存入本地持久化；刷新后可继续。
- 命册出现与落印由 Seedance 主片承载，创建表单使用 HTML 叠加；自由姓名始终是动态文字层，不烧进视频。

## 4. 字幕与语言

- 字幕默认开启，支持简体中文、繁体中文和英文。
- 角色说话、画外音、环境信息使用不同但克制的样式。
- 不把全部叙事烧录到视频。
- 自由玩家姓名只进入动态文字层。
- 重要环境声提供可选描述字幕，例如“门外传来急促脚步”。

## 5. 暂停与命册

暂停不是普通系统弹窗，而是打开无字命册：

- 当前章节；
- 继续播放；
- 字幕、音量、清晰度与辅助设置；
- 已发生的关键回响；
- 已发现线索；
- 返回封面。

未解锁关系和结局不显示灰色数值格，避免剧透；可显示模糊页签数量。

## 6. 存档与回放

- 自动存档发生在场景边界和选择确认后。
- “继续游玩”恢复到最近稳定节点，不恢复到视频中间无法保证连续性的任意帧。
- 已看视频支持跳过；首次观看不展示强干扰跳过按钮。
- 章节回放使用独立临时状态，不覆盖主存档，除非玩家确认以新路线继续。
- 结局后可查看本次关键回响和未探索分支提示，但不显示精确数值。

## 7. 媒体状态

必须有明确状态：

- 初始准备；
- 当前片缓冲；
- 下一分支预加载；
- 网络变慢；
- 媒体失败和重试；
- 浏览器不支持编码；
- 音频尚未解锁。

视觉播放不得等待音频系统 promise 才开始。用户手势后音频尽力解锁，失败时视频继续并显示可恢复提示。

切换静音不得重新挂载视频或从头播放。

## 8. 可访问性

- 所有按钮有可读名称、键盘焦点和可见焦点状态。
- 选择目标最小触控尺寸 44×44 CSS px。
- 不只用颜色区分选择、危险或成功。
- 支持减少动态、关闭镜头晃动和全景惯性。
- QTE 支持延长与无时限。
- 3D / 全景提供列表式等价操作。
- 字幕字号、背景和对比度可调。
- 任何限时选择在屏幕阅读器下必须有明确剩余时间和暂停能力。

## 9. 特殊按钮与视觉资产

- 播放、暂停、音量、返回等通用控制使用现有图标库，不生成位图按钮。
- 命册页签、印章、云锦纹样可由 Seedream 5 生成纹理或装饰层。
- 文字、命中区域、状态、焦点和本地化始终由 HTML / CSS 实现。
- 不把文字烧进按钮图片，不用 CSS 绘制假道具替代正式资产。

## 10. 验收问题

每个互动上线前回答：

1. 玩家为什么此刻能做这个动作？
2. 人物是否立即知道或感受到它？
3. 有什么可见后果？
4. 后面是否回收？
5. 不操作会怎样？
6. 键盘、触屏和辅助模式如何完成？
7. 媒体失败时是否能恢复？
