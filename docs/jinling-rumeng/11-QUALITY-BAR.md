# 正式产品质量门槛

状态：DRAFT · v0.1
最后更新：2026-07-10

## 1. 完成定义

“能够从头点到结尾”不等于完成。第一季只有在剧情、表演、媒体、交互、稳定性和可访问性同时达到门槛后才可视为可发布。

## 2. 剧情

- 玩家身份在前三分钟内成立。
- 第一季存在清晰表层目标、情感目标和悬疑目标。
- 所有原著锚点完整且不被原创玩家抢夺。
- 每个主要选择有即时反馈或后续回收。
- 每个结局依赖多个前置行为，并拥有独立影像。
- 没有不可达节点、假分支、无解释跳转和结局黑箱。

## 3. 表演与电影

- 演员视线准确面对玩家。
- 选择反应包含表情、动作、语气或距离变化。
- 人脸、年龄、服装、发饰和道具跨片一致。
- 相同空间的方向、光线、站位和底噪连续。
- 等待循环自然，不出现明显冻结或抽动。
- 视频无水印、乱码、现代物、肢体错误和不可接受的生成伪影。

## 4. 交互

- 玩家在每个互动点知道自己可以做什么。
- 对话、观察、物理动作、QTE、3D 和全景使用合适且不同的操作语言。
- 首次流程无死锁、无强制刷新、无无法退出状态。
- QTE 辅助模式与正常模式剧情等价。
- 暂停、继续、存档、回放、字幕和音量真实工作。

## 5. 媒体与性能

- 首屏和开场不下载整季内容。
- 当前片与下一候选片有明确预加载策略。
- 网络慢、媒体失败、编码不支持时有恢复路径。
- 切换静音、字幕和清晰度不重置剧情进度。
- 视频、音频、字幕时间线稳定同步。
- Three.js 和全景离开后正确释放资源。
- 桌面、手机和宽屏均通过构图与安全区验收。

具体性能预算在完成目标设备矩阵和首章最终媒体测试后锁定，不能用未经测量的数字假装承诺。

## 6. 声音

- 对白在手机扬声器与耳机上均清楚。
- 切场无突兀底噪、爆音和响度跳变。
- 静音状态仍可理解剧情与操作。
- 环境、Foley、音乐和互动反馈不互相遮蔽。
- 通灵宝玉、命册和关键人物拥有稳定声音识别。

## 7. 可访问性

- 所有核心操作可通过键盘和触屏完成。
- 控件有可读名称、可见焦点和足够点击尺寸。
- 字幕默认开启且可调。
- 色彩不是唯一信息来源。
- 支持减少动态、全景替代列表和 QTE 无时限。
- 使用屏幕阅读器时能理解当前模式、选项和状态变化。

## 8. 内容和数据

- 文档、机器 manifest 和运行时使用相同稳定 ID。
- 所有 i18n 文案齐全，不在 TSX 硬编码中文。
- Mock 存档有版本和迁移策略。
- 所有路径自动枚举通过。
- 缺失素材和非法配置在构建阶段失败。
- 不提交密钥、供应商完整响应、临时签名 URL 或敏感信息。

## 9. 生产验证章

在批量生产前，选择第一章按最终标准完整制作：

- 使用最终引擎；
- 使用正式人物与道具参考；
- 使用正式视频、声音、字幕和媒体编码；
- 包含至少一次选择、一次反应、一次回收和一次媒体失败恢复验证；
- 完成后直接保留为正式第一章，不建设临时 Demo 分支。

它的目的不是缩小产品目标，而是在放大生产前证明最终流水线能稳定复制。

## 10. 发布阻断项

以下任一存在即阻断：

- 角色在反应片明显变脸或换装；
- 选择后无可见反馈；
- 结局仅靠文字解释；
- 缺失素材被默认空镜掩盖；
- 开始游戏因音频初始化卡死；
- 存档刷新后丢失；
- 单次 QTE 失误直接锁死主要内容；
- 移动端关键人物或选项被裁切；
- 字幕与对白明显错位；
- 真实密钥进入 Git 变更。
