# 《金陵入梦》产品总纲

状态：REVIEWED · v0.4
最后更新：2026-07-11
范围：正式互动影游产品；第一季内容使用本地 Mock 数据，但产品能力按最终形态设计
准源：本目录是《金陵入梦》的产品与内容设计准源。代码、生成任务和素材不得反向覆盖已锁定设计。

## 1. 产品定义

《金陵入梦》是一款允许玩家创建原创角色，以第一人称进入《红楼梦》世界、参与经典主线并发展个人命运的真人互动影游。

玩家不扮演、替代或夺取任何原著人物身份。林黛玉、贾宝玉、王熙凤等原著人物保留自己的欲望、命运与叙事中心。玩家以“原著命册中不存在的人”进入故事，在原著事件之间建立属于自己的关系、秘密与后果。

第一季副标题：**第一季 · 无字来客**。

## 2. 核心体验承诺

1. 玩家创建的身份真实存在于世界中，所有人物能够看见、询问、信任、利用或怀疑玩家。
2. 人物以第一视角摄影语言直接面对玩家，选择后必须出现可见、可听的真人反应。
3. 原著关键事件按“锚点”保留；玩家改变事件的过程、局部后果、人物感受和自己的命运。
4. 早期选择必须在后续被人物重新提起，形成“人物记得我做过什么”的体验。
5. 结局必须以独立影像收束，不使用文字卡替代剧情结果。
6. 视频、3D、全景和网页交互按叙事需要组合，不以单一技术形态限制产品。
7. Mock 仅代表暂不入库。角色创建、存档、回放、关系、结局、媒体加载和错误处理必须真实工作。

## 3. 不可妥协原则

- 不以 Demo、MVP 或占位版本为目标。
- 不因现有素材、代码或生成成本形成沉没成本约束。
- 缺少关键素材或配置时明确失败，不静默回退到错误画面。
- 每个有效选择都有即时反馈、状态影响或后续回收；纯装饰选项不得伪装成分支。
- 角色、服装、道具、空间和声音必须跨镜头保持连续。
- 正式对白默认提供独立字幕；重要信息不得只依赖声音、颜色或限时操作。
- 任何媒体生成前，必须存在已评审的场景卡、分镜卡和素材编号。

## 4. 玩家与世界

玩家在“太虚幻境”的无字命册前创建原创角色。命册没有记录玩家的既定结局，只根据玩家选择逐步显字。

进入红楼世界后，玩家获得一个在世界内部成立的身份：受贾敏生前旧情与一封荐书牵引，作为贾母故交晚辈，与黛玉同日抵达荣国府。玩家可选择不同出身、专长和信物，但共同入口与主线保持收束。

详细规则见 [01-WORLD-AND-PLAYER.md](./01-WORLD-AND-PLAYER.md)。

## 5. 原著事件锚点

第一季必须发生：

- 林黛玉进入荣国府；
- 黛玉与贾母相见；
- 王熙凤出场并迎接黛玉；
- 王夫人提醒黛玉注意宝玉；
- 宝玉初见黛玉并说“这个妹妹我曾见过的”；
- 宝玉询问黛玉是否有玉；
- 宝玉因黛玉无玉而摔玉。

玩家不得替代黛玉承受这些事件，也不得让事件无条件消失。玩家可以改变：

- 自己如何进入、被谁担保；
- 黛玉是否信任玩家；
- 王熙凤如何判断并利用玩家；
- 宝玉对玩家产生好奇、亲近或戒备；
- 摔玉时玩家采取什么行动，以及动作产生的局部结果；
- 当夜谁知道玩家荐书的异常；
- 玩家留府、离府或发现无字命册真相。

## 6. 第一季范围

- 首次流程内容目标约 9 分钟；常见实玩 9–11 分钟，硬上限 12 分钟。
- 主场景：10 场，另含角色创建序章。
- 显式剧情选择：4 次；其余差异由历史状态、自动短变体或非阻断观察承载。
- 高潮交互：1 次摔玉多动作 QTE，必须有辅助模式。
- 选择反应片：每个选择至少一组，按四个选择及条件变体生产。
- 结局：4 个普通结局 + 1 个隐藏结局。
- 主要角色：玩家、林黛玉、贾宝玉、王熙凤、贾母、王夫人；门上与仆妇为功能性角色。
- 正式媒体预估：50–60 段视频，最终数量以逐镜任务与出身变体为准。

详细剧本见 [03-SEASON-01-STORY.md](./03-SEASON-01-STORY.md)。

## 7. 产品形态

运行时必须原生支持：

    电影视频场景
      → 真人选择场景
      → 即时反应片
      → QTE 场景
      → 3D 道具检查
      → 360°空间探索
      → 延迟回收
      → 独立影像结局

Three.js、GLTF、360°全景、Tone.js、Web Audio、GSAP、HLS 等能力按场景需要使用；技术不得成为脱离剧情的展示层。

## 9. 锁定流程

每份文档依次经过：DRAFT → REVIEWED → LOCKED。

- DRAFT：允许大改，不能触发批量素材生产。
- REVIEWED：结构与方向通过，允许小规模最终质量试制。
- LOCKED：稳定编号、台词、分镜和依赖确定，允许批量生产。

素材状态独立为：草稿 → 已评审 → 已锁定 → 生成中 → 待验收 → 已通过。

## 10. 当前已确认

- 玩家是可创建的原创角色，不是任何《红楼梦》原著人物。
- 体验使用第一视角，角色直接与镜头中的玩家交流。
- 现有影游素材和实现可以全部弃用。
- 第一季数据先本地 Mock，但产品结构按最终可上线形态设计。
- Seedream 5 用于人物、道具、场景和特殊纹理；Seedance 2.0 用于正式视频；SeedAudio 用于声音生产。
- 可按叙事需要使用 Three.js、3D、全景、Tone.js 等技术。
- 玩家是红楼世界内生成的原创人物，不采用现代穿越者口吻。
- 第一季保留江宁织造、贾府故交、金陵医馆三种出身。
- 荐书由无字命册写入世界；旧署名与旧纸关系真实，淡红封印是可被发现的异常。
- 影游以视频为默认视觉主轨；HTML/Canvas 负责交互与动态身份，3D/全景只作为显式高级节点。
