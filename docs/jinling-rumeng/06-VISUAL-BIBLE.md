# 视觉、摄影与界面圣经

状态：REVIEWED · v0.2
最后更新：2026-07-10

## 1. 视觉定位

关键词：真实古装电影、克制华丽、灯影与秩序、第一视角亲密感、太虚幻境的纸与雾。

荣府不是旅游宣传片，也不是持续金红饱和的宫廷景观。空间越华丽，人物越应被门槛、帘幕、座次和视线限制。太虚幻境与现实荣府通过纸张、印泥、灯火和水面反射形成视觉关联。

### 已选视觉基准：水墨实景

正式基准图：[VISUAL-DIRECTION-01-WATER-REALISM.png](./visual/reference/VISUAL-DIRECTION-01-WATER-REALISM.png)

选定特征：

- 写实历史空间优先，超自然感通过水面、纸张和不可能的印纹出现；
- 无字命册是可触摸的真实物件，也是角色创建界面；
- 秦淮水面、荣府建筑和人物剪影形成真实空间纵深；
- 月色冷调与远处灯火暖调并存；
- 淡红纹印是唯一强色和长期视觉线索；
- UI 融入物件，但文字、选项和点击区域仍由网页层实现。

基准图不是最终界面截图。正式实现必须修正三种出身图形、建筑考据、淡红纹印强度、移动端构图和按钮的网页可访问性。

## 2. 两个世界

### 荣国府

- 材质：真实木、漆、织物、纸、石，不使用塑料般高光。
- 色彩：深木、黛青、月白、旧金；红色用于灯、印和少量权力信号。
- 光线：室内以窗光、灯火和反射为主，有明确光源方向。
- 镜头：稳定、克制、人物距离真实；不滥用慢动作和无人机式漂浮。

### 太虚幻境

- 核心元素：无字纸页、雾、水面、远处人影、未干的淡红印。
- Three.js 负责空间和命册交互，生成资产负责真实纸张、纹理、远景和粒子贴图。
- 不使用通用紫色星空、霓虹光圈、科幻 HUD。
- 主方向采用“真实秦淮水面进入太虚”的水墨实景；黑漆秘阁可作为熙凤线与夜间室内材质参考，纸页廊桥仅用于重大章节转场，不成为常驻主视觉。

## 3. 第一视角摄影

- 镜头高度在全部片段中保持一致，除非剧情明确坐下、跪下或摔倒。
- 演员目光准确落在镜头光轴，不看摄影师旁边。
- 递物方向、玩家站位和角色距离必须记录在分镜连续性表。
- 选择等待片需要自然动作：呼吸、移开再回看、手指停在物件上；不能僵硬定格。
- 角色靠近镜头应服务压迫、亲密或检查，不为制造廉价刺激。
- 不随意展示玩家脸；镜面用遮挡、浅景深或不完整倒影处理。

## 4. 角色连续性

Seedream 5 先生成并锁定：

- 角色主参考图；
- 头部多角度；
- 全身比例；
- 基础表情；
- 每场服装；
- 发饰、首饰和持物；
- 同场角色比例对照。

Seedance 2.0 任务只能引用已锁定参考包。若人物脸、年龄、服装、手指、道具或空间方向不一致，素材状态不能进入“已通过”。

## 5. 场景连续性

每个场景建立空间卡：

- 平面关系与人物站位；
- 门窗方向；
- 主光源；
- 关键家具与道具位置；
- 玩家进入和离开方向；
- 可用于选择的等待构图安全区。

同一场景的主片、等待循环、选择反应和汇合片必须共享空间卡。

## 6. UI 方向

- 电影播放时界面近乎隐形。
- FizzDragon 品牌红只用于当前选择、关键焦点、危险和确认，不铺满页面。
- 命册 UI 以真实纸页、墨、印为视觉语汇，但所有文字与控件保持网页可读性。
- 通用控件使用项目现有图标体系。
- 不使用漂浮玻璃卡片堆满电影画面。
- 不常驻显示数值、进度和人物好感条。

## 7. Seedream 5 资产类型

- CHARACTER-REF：人物定妆与角度参考。
- COSTUME-REF：单场服装与饰品。
- LOCATION-REF：空间概念、平面方向和灯光。
- PROP-REF：道具正反面、手持与特写。
- UI-TEXTURE：纸、印、云锦与章节装饰纹理。
- MATTE：太虚幻境远景、雾层和可合成背景。

生成图不直接因为“好看”进入产品。必须满足用途、尺寸、构图、安全区和连续性要求。

## 8. 视频母版与交付

- 生产母版优先高质量、高码率，发布时生成 H.264 / H.265 或 HLS 派生版本。
- 画幅以 16:9 为主，同时记录移动端安全裁切区。
- 每段视频提供 poster、首尾帧、时长、音轨信息和字幕引用。
- 选择等待点必须有可循环尾段或独立 loop clip。
- 不把 UI、自由姓名和多语言字幕烧进母版。

## 9. 视觉验收

每个镜头检查：

- 人脸和年龄是否连续；
- 服装层级是否符合人物身份；
- 手指、发饰、玉、信件和印章是否完整；
- 空间方向是否能与前后镜头拼接；
- 演员是否真正看向玩家；
- 选择 UI 是否遮挡表演；
- 手机安全裁切是否保留关键信息；
- 是否出现现代物、乱码、假文字或生成水印。
