# 声音与音乐圣经

状态：DRAFT · v0.1
最后更新：2026-07-10

## 1. 声音目标

声音不是给静态画面铺一层古风音乐。它必须建立空间、人物距离、权力关系和互动反馈。

声音层级：对白 > 关键动作 > 环境空间 > 情绪音乐 > UI 反馈。

## 2. 声音生产

SeedAudio 可用于：

- 角色声音方向测试；
- 临时对白参考；
- 环境声景；
- 音乐分轨与情绪变体；
- 电影音效和交互反馈。

最终音轨必须经过剪辑、响度、噪声、空间和连续性验收。生成结果不能未经处理直接作为正式混音。

## 3. 角色声音

每个主要角色建立声音卡：

- 基础音色；
- 语速和停顿；
- 情绪范围；
- 距离感；
- 禁止风格；
- 参考台词；
- 跨场一致性样本。

自由玩家姓名不进入预录对白。演员使用自然中性称呼，动态字幕可显示姓名。

第一季玩家使用一套锁定的成年画外主角声线。玩家选项不是无声意图，而是实际说出的台词或实际执行的动作；所有语言选择必须有玩家对白分轨，并由 NPC 在同镜或紧接的反应片中听见和承接。自由姓名不进入预录对白。

玩家声音方向：青年成年声线，音域居中，咬字清楚，情绪克制，有礼但不怯弱；不使用现代口语、偶像剧气声、广播腔或性别夸张表演。对白先以独立单声道干声生产，按固定时间码与场景 room tone、NPC 对白和拟音混成最终嵌入音轨。未来增加声线选择时只替换玩家对白分轨，不复制视频。

## 4. 场景声音

每场至少拆分：

- DIALOGUE：对白；
- ROOMTONE：空间底噪；
- FOLEY：衣料、脚步、纸、玉、木门；
- AMBIENCE：风、远处人声、庭院、河水；
- MUSIC-STEM：音乐分轨；
- INTERACTION：选择确认、命册落印、线索发现。

不把所有层混成唯一无法调整的音轨。媒体交付应允许运行时对白与动态音乐协作。

## 5. 动态音乐

Tone.js / Web Audio 仅用于真正需要互动变化的音乐层：

- 熙凤怀疑上升时加入低频或节奏层；
- 黛玉信任时减少压迫声部，而不是播放甜蜜提示音；
- QTE 根据玉离手、玩家动作和后果片切换短促层；
- 太虚幻境用可持续、可变化的音色响应命册操作。

正式主题、主要旋律和电影段落仍使用可控的 SeedAudio 音乐分轨或正式制作音源。程序音乐不得产生随机、无法复现的情绪结果。

## 6. 空间与连续性

- 同一房间主片和反应片共享 room tone。
- 角色从远处走近时声音距离连续。
- 门、帘、廊和房间改变混响，而不是只改音量。
- 同一动作跨分支使用一致的物理音色，例如通灵宝玉不能每段听起来材质不同。
- 视频切换不得出现底噪骤停、音乐重启或响度跳变。

## 7. 字幕与可感知性

- 所有正式对白有时间码字幕。
- 关键非语言声音提供可选描述字幕。
- QTE 提示不只依赖声音。
- 静音状态下仍能理解全部剧情和操作。

## 8. 响度与交付

发布前统一：

- 对白清晰度；
- 综合响度目标；
- 峰值限制；
- 音乐对白闪避；
- 耳机与普通手机扬声器验证；
- 循环点无爆音；
- 多语言字幕时码一致。

具体响度数值在完成播放端和目标平台验证后锁定，不在草案阶段随意写死。

## 9. 第一季关键声音母题

- 无字命册：纸页、远水、极轻人声倒影、淡红印落下的低频触感。
- 黛玉：气息、衣料和克制弦音，不用固定“好感提示音”。
- 熙凤：节奏与空间突然变得清楚，笑声后的安静比反派音效更危险。
- 宝玉与通灵玉：玉石、丝绦和少年情绪；摔玉声必须成为第一季记忆点。
- 秦淮与荣府：水声在府中逐渐消失，结局时根据路线重新出现。
