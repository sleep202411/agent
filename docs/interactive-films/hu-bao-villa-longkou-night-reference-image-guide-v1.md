## 1. 到底需要哪些人物

只有两个人需要稳定、清晰、可跨 21 段复用的真人身份参考。

| 人物               | 是否需要清晰人物参考           | 在视频中的呈现                                                   |
| ------------------ | ------------------------------ | ---------------------------------------------------------------- |
| 陈澄               | **需要**                       | 全片玩家角色，清晰正脸、侧脸、全身、手持卡带机                   |
| Maya Rahman        | **需要**                       | 全片同行者，清晰正脸、侧脸、全身、手持 DV                        |
| 林国声             | **需要轮廓参考，不需要清晰脸** | 只在控制室玻璃反影、CRT、远处剪影中出现，永不正面清晰露脸        |
| Salmah Binte Yusof | **不需要人物形象**             | 只通过录音、工牌、日志和展览平面存在；禁止生成她的鬼魂或真人角色 |
| 1994 游客残影      | **不需要身份参考**             | 半透明、无清晰可辨人脸的背景群像                                 |

因此，角色生产不是“四个人物立绘”，而是：**陈澄角色包、Maya 角色包、林国声回声轮廓包，共 3 套；Salmah 不做人像。**

## 2. 角色视觉锁定

以下细节一经选定，不得在后续参考图或视频里重新发挥。

所有参考图任务统一追加以下负向约束：

```text
不要文字、字幕、logo、水印、品牌、海报排版、概念艺术笔触、动漫、3D 卡通、过度磨皮、网红脸、时尚大片、赛博霓虹、魔法粒子、血腥、身体恐怖、额外人物、重复人物、多手、多指、融合手、错误透视、道具漂浮、背景乱码。
```

## 9. 每张参考图的通用拒收项

任何一项出现就重做：

- 陈澄或 Maya 与已批准身份肖像不是同一张脸。
- 角色年龄明显变大、过度美化、网红化或时尚大片化。
- 服装颜色、发型、耳机、背带方向、DV 手持侧发生变化。
- 卡带机、DV、工牌和控制台在不同图中换设计或比例。
- 场景出现赛博霓虹、魔法粒子、血肉化龙口、欧洲建筑或现代游乐园人群。
- 林国声出现清晰正脸，或 Salmah 被生成为真人/鬼魂。
- 图片模型生成乱码、伪 Logo、真实机构标志或水印。
- Join Frame 中关键脸、手或道具落入下中部交互 UI 覆盖区。
- JF-02 仍戴着单只耳塞，导致 S02A 与 S02B 无法共用同一尾帧。
- JF-03 之后卡带湿度、Maya 右掌轻伤或 DV 归属不一致。
