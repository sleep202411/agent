# 影游界面自定义契约

创作者在已有 FizzDragon 影游项目内，通过官方 DeepSeek Harness 修改作品界面，
在同一播放器中试玩并保存到项目。影游运行时继续拥有章节、视频、剧情、选项、
数值、访问规则与存档。完整服务、菜单源码和会话托管契约见
[影游自定义与对话编程设计](game-vibecoding-production-design.md)；本文聚焦原生界面的
CSS/SVG 呈现契约。

## 产品边界

从项目进入试玩后，左侧运行真实作品，右侧显示官方 Harness 对话。
Harness 负责对话与工具循环，平台不再实现另一套聊天渲染器或 Agent 循环。
`apps/game-agent` 独立于 Agent OS；Server 验证账号和项目权限，并拥有保存与发布权威。

工作流程为：打开项目 → 描述修改 → 读取当前外观 → 检查并提交提案 → 左侧试玩 →
保存到项目 → 现有 Build / 发布。候选、最后可运行预览、已保存草稿与已发布版本
是不同状态。编译失败保留候选和最后可运行版本；版本冲突不能静默覆盖他人修改。

作品可以自由使用符合内容风格的色彩与静态装饰。Studio 外壳仍遵循平台设计系统。
登录、支付确认、权益拦截、平台错误及导航由平台呈现，作品主题不能替换或遮挡。
主题只改变已有行为的呈现；画出密码盘、背包或地图不代表运行时已支持相应玩法。
新增玩法应扩展同一影游 SDK 和状态契约。

## 单一外观来源

当前外观文档仅接受：

```ts
{
  version: 1,
  presentation?: {
    theme?: { version: 1, name: string, css: string, assets: { id: string, svg: string }[] },
    copy?: { start: { "en-US"?: string | null, "zh-CN"?: string | null, "zh-HK"?: string | null } }
  }
}
```

CSS/SVG 主题是唯一视觉来源。开始按钮文案独立保存，`null` 恢复该语言的平台默认值；
加载中和开始中的文案、按钮行为仍由运行时控制。主题编辑替换整份主题，文案局部编辑
保留其他语言和已有主题。

旧皮肤参数和区域样式对象不进入新工具、播放器或新保存接口。已有项目和浏览器草稿
在读取入口转换为当前格式，保留原 CSS 优先级、素材和文案；转换失败明确报告并保留
原数据，不清空或重置作品。自定义主菜单源码是另一个隔离挂载能力，不叠加成第二套
原生界面样式来源。

## 语义区域和真实动作

`EXPERIENCE_UI_CONTRACT` 声明四个当前区域。主题选择器使用
`data-experience-ui-region` 和 `data-ui-part`；AI 不能自造剧情选项或替换动作处理器。

| 区域       | 公开部件                                                       | 运行时动作                             |
| ---------- | -------------------------------------------------------------- | -------------------------------------- |
| `start`    | `panel`, `eyebrow`, `title`, `summary`, `primary`, `secondary` | 开始、继续、重新开始、打开真实地图     |
| `playback` | `controls`, `progress`, `pause`, `rate`                        | 暂停／恢复、受已看范围限制的跳转、倍速 |
| `choices`  | `prompt`, `list`, `option`, `index`, `price`                   | 选择真实可见且可访问的选项             |
| `pause`    | `panel`, `title`, `summary`, `primary`, `secondary`            | 恢复或按当前状态重新开始               |

共享播放器持有可用性、重入保护、已失效回调检查、收费与权限检查。主题不能改变价格、
锁定状态、真实文案来源或剧情结果。可信的 `ExperiencePlayerUI` React 扩展点由平台代码
实现；模型生成主题不执行 React、HTML 字符串或事件处理器。

## CSS 与 SVG 校验

共享编译器用 CSS AST 和 SVG XML 节点校验生成内容，Studio、工具、Server 保存与
Build 使用同一契约。当前能力以 `EXPERIENCE_THEME_CAPABILITIES` 为准，避免工具提示
和保存校验各维护一套白名单。

- 选择器仅能命中公开区域和部件，支持规定的交互状态及 `::before` / `::after` 装饰。
- 区域根节点只允许绘制与对齐；真实控件保持可见、可点击及最小触摸尺寸。
  绝对定位只用于不接收指针事件的装饰，不用于移走真实控件。
- 支持经过校验的排版、Flex/Grid、颜色、渐变、边框、阴影、有限变换和过渡。
  响应式规则使用预览容器的 `@container` 尺寸。
- `asset("id")` 只能引用当前主题声明的静态 SVG。SVG 禁止脚本、事件、外部引用和
  未授权节点；字体使用本地／系统字体栈，不下载外部字体。
- 禁止全局选择器、外部样式导入、任意 URL、脚本表达式、`!important` 及隐藏或伪造
  真实进度与交互控件的规则。主题大小、规则数、素材数和数值范围均有编译上限。

当前上限为 CSS 32,000 字符、最多 160 条规则、8 个 SVG 素材（每个 16,000 字符）和
编译 CSS 131,072 字符。精确属性和值约束以源码能力表与编译器为准。检查通过表示
符合契约，不代表所有画幅、语言、交互状态和设备均已完成视觉验收。

## 播放与窗口行为

Web 与 Studio 使用同一共享播放器。视频保持作者画幅，封面完整显示；布局按左侧
游戏窗口响应，而不是按整个编辑页面响应。真实控件保留 44px 最小目标、键盘焦点、
可滚动内容和系统减少动态效果支持。播放条测量真实高度，避免遮挡选项；修改主题
不能重新挂载媒体或重置剧情会话。

预览 iframe 将地图、弹窗、快捷键、焦点和样式限制在游戏窗口。右侧官方对话保持
独立。生成的主菜单源码再运行于 opaque-origin iframe，经有边界的 Game SDK 与
播放器交互；该源码能力的 CSP、消息校验、构建与动作限制见配套设计。

## 草稿、工具与版本

工作台以项目范围的 Zustand 状态保存当前草稿、输入、项目基准版本与撤销检查点。
官方 Harness 保存对话和服务端候选文件。浏览器持久化按源码／产物哈希去重，最多
保留 40 个撤销检查点并按 2 MiB UTF-16 预算裁剪旧记录。当前修改保留在内存；写入
配额失败显示保存失败，并保留既有持久草稿。

单次设计和官方聊天共用 `appearance-harness-plugin` 的读取、校验与提交工具。
模型不能扩大工具权限。提交检查请求版本，拦截取消、过期、重复或未变化的结果，
原子保存有效提案。源码文件工具仅在官方聊天宿主开放，恢复候选后仍需重新检查。

Server 保存时重新校验／编译，按项目权限和版本比较写入；不信任客户端产物。
Build 固定已保存外观与菜单产物，正式玩家不重新编译。样式变更、保存冲突和发布
失败沿用现有项目恢复流程，不建立另一套作品或存档系统。

## 部署与验收范围

Game Agent、Server 和 Studio 已部署到 `.com` 新加坡 ACK。日常发布使用
[新加坡发布流程](../../deploy/aliyun-sg/README.md)，从干净 `main` 的固定 HEAD 构建，
保留 Harness 的持久工作区。源码、容器就绪和单元测试不能替代真实用户流程验收。

已有私有环境验证覆盖真实账号的项目准入、模型对话、工具修改、项目保存／重载和
优雅 Worker 重启后恢复同一会话；恢复曾需要手动 Reconnect。新版本仍应按实际修改
验证公开域名下的登录、试玩、保存、恢复与 Build / 发布。强制崩溃、完整移动设备体验、
全部素材与支付流程没有因这些检查自动获得验收。

当前菜单 SDK 只提供开始、继续、重开、真实地图开关和返回菜单。任意游玩界面源码、
完整地图数据、数值读写和通用项目素材接口尚未提供；它们需要明确扩展契约，不能用
主题生成或独立游戏导入来假装已支持。

## 实现入口

- `packages/shared/src/experience-runtime/ui.ts`：区域、文案和动作契约。
- `packages/shared/src/experience-runtime/ui-theme.ts`：主题能力与统一编译器。
- `packages/shared/src/experience-runtime/appearance.ts`：外观 schema。
- `packages/experience-player-react`：共享渲染、宿主动作和菜单隔离。
- `apps/game-agent/src/tools`：官方 Harness 工具。
- [Game Agent 服务说明](../../apps/game-agent/README.md)：会话、代理和持久工作区。
