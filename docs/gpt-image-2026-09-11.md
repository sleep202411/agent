# GPT Image catalog update — 2026-09-11

GPT Image 2 now accepts 16 references. Its nine resolution/quality rates and both
reference surcharges are reduced by 30% from the repository's previous prices.
This is an idempotent replacement, not a repeated percentage discount on each seed.
Quotes still round up the final total to whole compute points.

| Resolution | Low | Medium | High |
| --- | ---: | ---: | ---: |
| 1K | 14 | 42 | 84 |
| 2K | 21 | 63 | 126 |
| 4K | 31.5 | 98 | 196 |

The first reference surcharge is 10.5 points per output, and additional references
are 3.5 points each under the existing billing formula. Default 1K/medium output:
60 → 42 points. A 4K/low output without references rounds 31.5 → 32 points.

## GPT Image 2.5

Separate canonical models: `gpt-image-2.5-flare` and `gpt-image-2.5-sunburst`.
Flare prioritizes speed; Sunburst prioritizes precision. Both have separate
`text-to-image` and `edit` bindings, with editing also handling masks.

Reviewed sources:

- [Flare API](https://fal.ai/models/openai/gpt-image-2.5/flare/edit/api)
- [Sunburst API](https://fal.ai/models/openai/gpt-image-2.5/sunburst/edit/api)
- [Flare pricing](https://fal.ai/models/openai/gpt-image-2.5/flare/text-to-image)
- [Sunburst pricing](https://fal.ai/models/openai/gpt-image-2.5/sunburst/text-to-image)
- [Image 2 edit API](https://fal.ai/models/openai/gpt-image-2/edit/api)

Both 2.5 variants expose 16 references, 32,000 prompt characters, low/medium/high/
xhigh/max quality, PNG/JPEG/WebP, background selection, masks, and 1–10 outputs.
The queue OpenAPI explicitly permits 10 outputs; its model overview's four-output
summary is narrower. Compact OpenAPI snapshots are checked into the seed catalog.
Provider `auto` quality is not offered because the platform quotes an explicit tier.
Output compression uses the provider default; sync mode remains disabled so media
results use the existing queued job pipeline.

The initial platform prices for both variants match discounted Image 2 at low/
medium/high, with xhigh/max at 2x/4x high. Default high/1K is 84 points. These are
curated selling prices. Upstream token cost is usage-dependent; token rates are
recorded separately and actual costs use the existing fal accounting path.

GPT dimension conversion now respects 16-pixel steps, the minimum 655,360 pixels,
maximum 8,294,400 pixels and 3,840-pixel edge. “1K” wide formats may exceed a
1,024-pixel long edge to satisfy the provider's minimum image area.

## Apply

Server deployment alone does not seed catalogs. First deploy the server changes,
then apply the three scoped model records and let the catalog cache refresh.
Run from `apps/server`:

```sh
# Offline review; no database connection, no writes.
npx tsx prisma/seed/update-gpt-image-catalog.ts --dry-run

# Local database only (loads DATABASE_URL and rejects a remote host).
node scripts/ensure-local-database.mjs npx tsx prisma/seed/update-gpt-image-catalog.ts --apply
```

The server build compiles this script and its dependencies into `dist/catalog-update`,
which the production Docker image already copies. It requires neither source files
nor a TypeScript runtime in the production container. From `/app/apps/server`:

```sh
node dist/catalog-update/prisma/seed/update-gpt-image-catalog.js --dry-run
# Run only as part of an authorized catalog update:
node dist/catalog-update/prisma/seed/update-gpt-image-catalog.js --apply
```

The script upserts these three canonicals
and their bindings only; it does not prune the catalog or update membership plans.
Existing disabled provider accounts stay disabled. Existing operational overrides
on these three canonicals are replaced by the reviewed seed configuration, so
review the plan against live configuration before an authorized production apply.
No production database update or paid generation was performed during this change.

Tests exercise real seed plans → catalog registration → server validation → fal
request mapping → submit/poll, with fal network calls mocked. They cover 16 vs 17
references, all image dimensions, explicit quality prices, and correct edit routes.
