# Seedance 风格视频提示词

> ⚠️ **重要：当此 Skill 生效时，video_prompt 列必须严格按照以下 Seedance 多镜头格式输出。不要使用普通描述性句子，必须包含镜号、子镜头时间轴、运镜方式、景别角度。语言必须跟随用户对话语言（用户用中文就全部用中文）。**

> 📚 **Seedance 多镜头分镜格式规范**
>
> - 每个镜号包含多个子镜头，带精确时间轴
> - 适合 Seedance 2.0 等支持长视频的模型

---

## 一、结构格式

```
镜号N（总时长）

第一镜头：（起始-结束秒）
运镜方式，景别+角度，动作/场景描述，台词

第二镜头：（起始-结束秒）
运镜方式，景别+角度，动作/场景描述，台词

...
```

---

## 二、核心要素

### 1. 镜号 (Shot Group)

- 一个镜号 = 一个连续场景，包含多个子镜头
- 总时长标注在镜号后：`镜号1（10秒）`
- 建议每个镜号 5-15 秒

### 2. 子镜头 (Sub-shot)

- 每个子镜头标注精确时间范围：`第一镜头：（0-2秒）`
- 时间必须连续，不重叠：0-2秒 → 2-7秒 → 7-10秒
- 每个子镜头独立描述运镜、景别、动作

### 3. 运镜方式

- 固定镜头、跟随镜头、快切、慢推、拉远
- 可组合：`镜头快速拉回给到两人手部特写`

### 4. 景别 + 角度

- 景别：全景、中景、中近景、近景、特写、手部特写
- 角度：正视、侧拍45度角、俯拍45度角、俯拍
- 组合：`近景侧拍45度角`、`特写固定镜头，俯拍45度角`

### 5. 动作描述

- 具体动作：`小猴子快速起身准备离开`
- 画面调度：`从画左出画`、`背身画右入画`
- 镜头衔接：`镜头缓缓推进到两人近景定住`

### 6. 台词 / 旁白

- 直接引用：角色名 + 冒号 + 台词
  - `盲眼老人缓慢地说："我不知道是谁"`
- OS（画外音）：角色名 + OS
  - `小猴子OS："我絕不會歸還个项链的"`
- 描述性台词：`蕃长温和的带着微笑的说到："我懂你意思了"`

## 三、完整范例

```
镜号1（10秒）

第一镜头：（0-2秒）
固定镜头，近景侧拍45度角，盲眼老人缓慢地说："我不知道是谁。但我知道那是条蕃长的船"

第二镜头：（2-7秒）
中景正视视角，跟随镜头，小猴子快速起身准备离开，镜头快速拉回给到两人手部特写，盲眼老人拉住小猴子，镜头缓缓推进到两人近景定住，盲眼老人递过麻布包说到："把这东西还回去，这个失主你惹不起，不祥之物啊。"镜头下摇推进，特写固定镜头，俯拍45度角，盲眼老人把手中麻布包放到小猴子手中。

第三镜头：（7-10秒）
快切近景，小猴子转身走开，大树下盲眼老人变得越来越小，小猴子从画左出画。跟随镜头，镜头跟着小猴子慢慢拉到全景。
小猴子OS："我絕不會歸還个项链的，我要用它换船票，我已經打定主意離開廣州城了。"
```

```
镜号2（8秒）

第一镜头：（0-2秒）
全景固定镜头，小猴子背身画右入画，跟随镜头，走进蕃长庭院，蕃长坐在铺着毯子软垫的榻上。

第二镜头：（2-8秒）
快切近景固定镜头，蕃长在闭目养神，说到："坐吧"
镜头快切特写俯拍，蕃长伸手指了指旁边的软垫
切近景固定镜头，小猴子坐在蕃长左边。
```

---

## 四、输出要求

1. **必须跟随用户对话语言**（用户用中文则全部中文，禁止混用英文）
2. 每个镜号总时长 5-15 秒
3. 子镜头时间必须连续且覆盖完整时长
4. 每个子镜头必须包含：运镜方式 + 景别角度 + 动作描述
5. 台词用引号包裹，标注说话人
6. 画面调度明确（入画/出画方向、镜头移动轨迹）
7. 光线和氛围在需要时描述（如 `灯光昏暗`、`窗內亮光有些泛红`）
